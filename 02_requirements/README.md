# 02 — Requirements

Formal requirements derived from the CEO survey. This is the single source of truth for what the engineer builds.

## Contents

| File | Description |
|---|---|
| `technical-spec.md` | Full technical specification — features, data models, API, roles *(pending CEO survey)* |
| `user-stories.md` | User stories in the format: "As a [role], I want to [action] so that [outcome]" *(pending)* |
| `acceptance-criteria.md` | Definition of done for each feature *(pending)* |

## Rules
- Nothing gets built without a corresponding entry here.
- Any change in scope must be updated in this folder first, then communicated to the engineer.
- PM owns this folder. Engineer reads and raises questions via comments or meeting.
