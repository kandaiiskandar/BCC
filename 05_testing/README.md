# 05 — Testing

Test plans, QA checklists, and bug reports. Both PM and Engineer contribute here.

## Contents

| File | Description |
|---|---|
| `test-plan.md` | Overall testing strategy and scope *(create before Phase 1 testing)* |
| `qa-checklist.md` | Feature-by-feature checklist for sign-off *(create per phase)* |
| `bug-reports/` | Individual bug report files *(create as issues are found)* |
| `uat-feedback.md` | CEO / user acceptance testing feedback *(create before each release)* |

## Testing Phases

| Phase | Type | Who |
|---|---|---|
| Unit testing | Code-level tests | Engineer |
| Integration testing | Features working together | Engineer |
| QA testing | Full feature walkthrough | PM |
| UAT | CEO tests the real system | CEO + PM |
